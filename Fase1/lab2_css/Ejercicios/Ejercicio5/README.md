# Ejercicio 5 — MoKaChiMo

Recreación y optimización de la web de **MoKaChiMo**, construida a partir de los Ejercicios 1 y 3 proporcionados.

## Archivos

- `index.html` — inicio
- `menu.html` — menú y tabla de granos
- `reservas.html` — reservas y formulario
- `styles.css` — estilos, selectores avanzados, pseudo-clases, pseudo-elementos, animaciones y responsive
- `assets/inicio.png`
- `assets/menu.png`
- `assets/reservas.png`
- `assets/carta.pdf`
- `JUSTIFICACION_DISENO.md`
- `QA.txt`

## Puntos importantes

- 3 páginas conectadas.
- Cero etiquetas `<div>`.
- Cero atributos `style=""`.
- CSS externo.
- Grid y Flexbox.
- Selectores de atributos y combinadores.
- `:is()`, `:where()` y `:has()`.
- Pseudo-elementos.
- Animaciones y transiciones.
- Media queries.
- `prefers-reduced-motion`.
- Tabla con `rowspan` y `colspan`.
- Formulario con validación HTML.

Uso de pseudo-clases

Las pseudo-clases permiten seleccionar elementos de acuerdo con un estado, una interacción del usuario, una condición de validación o una posición dentro de la estructura HTML. La guía exige al menos diez casos; esta evidencia implementa dieciocho.

Cómo probar la página

Pase el cursor sobre enlaces y controles, navegue con Tab, complete los campos, marque opciones y use los enlaces del menú. Cada acción activa distintas reglas de pseudoclases.css.

Reglas estructurales visibles

La lista utiliza :first-child, :last-child, :nth-child(odd) y :not(:last-child) para diferenciar elementos según su posición.

Registro y conclusión

Se probaron estados de navegación, interacción, foco, validación, selección y posición estructural. Las pseudo-clases permiten reaccionar al contexto actual del elemento sin modificar el HTML cada vez que cambia dicho estado.

Diferencia entre pseudo-clase y selector de atributo

El selector de atributo consulta información declarada como type, required o data-*. La pseudo-clase consulta una condición dinámica o estructural como :hover, :valid, :checked o :nth-child().

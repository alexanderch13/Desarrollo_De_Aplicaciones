Uso de pseudo-elementos

Los pseudo-elementos permiten aplicar estilo a una parte específica de un elemento o insertar contenido visual generado desde CSS sin añadir nodos HTML innecesarios. La guía exige siete casos; esta evidencia presenta ocho.

Registro y conclusión

Se verificó que los pseudo-elementos permiten trabajar con fragmentos virtuales como la primera letra, la primera línea, los marcadores y el placeholder, además de generar contenido decorativo antes o después de un elemento.

Diferencia entre pseudo-clase y pseudo-elemento

Una pseudo-clase selecciona un elemento cuando cumple un estado o condición, por ejemplo :hover o :checked. Un pseudo-elemento selecciona o genera una parte del elemento, por ejemplo ::first-letter, ::before o ::marker.

# Experiencia de Práctica N° 04 — CSS

## Tema
**Selectores combinados, múltiples, Regex, herencia y cascada.**

Esta carpeta contiene las tres evidencias solicitadas en la guía de la Sesión N° 02. Se mantiene la línea visual OWASP/ciberseguridad de las experiencias anteriores y se evita completamente el uso de etiquetas `<div>`.

## Estructura

- `index.html` + `combinadosymultiples.css`: selectores combinados y múltiples.
- `regex.html` + `regex.css`: selectores Regex/patrones de atributos.
- `herenciaycascada.html` + `hereciaycascada.css`: herencia y cascada.
- `base.css`: presentación visual compartida.
- `REGISTRO_Y_CONCLUSIONES.md`: registro de comprobación y conclusiones.
- `QA.txt`: validaciones automáticas básicas.

## Cumplimiento mínimo

### A. Combinados y múltiples
- 10 casos combinados documentados (mínimo exigido: 7).
- 5 agrupaciones múltiples principales (mínimo exigido: 5).

### B. Regex
- 8 casos de coincidencia por atributos (mínimo exigido: 5).

### C. Herencia y cascada
- 7 casos de propiedades heredables.
- 5 demostraciones de cascada.

## Criterios de calidad aplicados

- HTML5 semántico.
- Cero etiquetas `<div>`.
- Sin estilos `style=""` en el HTML.
- Separación entre estructura y presentación.
- Diseño responsive.
- Tablas de datos con `caption`, `colgroup`, `col`, `thead`, `tbody`, `rowspan` y `colspan`.
- `meta description`, `charset` y `viewport` configurados.
- Navegación interna y jerarquía coherente de encabezados.

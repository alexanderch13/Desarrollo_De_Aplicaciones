Herencia y cascada en CSS

La herencia permite que determinadas propiedades definidas en un elemento padre se transmitan a sus descendientes. La cascada determina qué declaración gana cuando varias reglas intentan aplicar valores distintos al mismo elemento.

Requisitos cubiertos

Se implementan 7 casos de herencia y 5 casos de cascada, superando exactamente los mínimos indicados por la práctica.

Siete casos de herencia

En cada artículo la propiedad se define en el elemento padre y los descendientes la reciben sin repetir el valor en cada nodo.

H1 // color

Este párrafo y su énfasis interno reciben el color del artículo padre.

H2 // font-family

Los descendientes utilizan la familia tipográfica establecida en el padre.

H3 // font-size

El tamaño de fuente se transmite a los elementos de texto descendientes.

H4 // line-height

La altura de línea heredada incrementa el espacio vertical entre las líneas de este contenido.

H5 // letter-spacing

El espaciado entre caracteres proviene del artículo padre.

H6 // text-align

La alineación central se hereda y afecta a este párrafo.

H7 // text-transform

El texto descendiente se presenta en mayúsculas por herencia.

Cinco casos de cascada

Cada evidencia provoca deliberadamente un conflicto entre declaraciones para comprobar qué regla tiene prioridad.

CA1 // Orden de origen

Dos reglas idénticas declaran colores distintos. Al tener la misma especificidad, gana la regla escrita después.

CA2 // Clase contra elemento

La clase tiene mayor especificidad que el selector simple p.

CA3 // ID contra clase

El ID tiene prioridad frente a la clase cuando ambas reglas son normales.

CA4 // Selector compuesto

El selector compuesto que incluye elemento, clase y atributo supera a la clase simple.

CA5 // !important

La declaración marcada con !important vence a la declaración normal del ID. Debe emplearse con precaución.

Registro y conclusión

La experiencia permitió distinguir dos procesos diferentes: la herencia evita repetir determinadas propiedades textuales en todos los descendientes, mientras que la cascada resuelve conflictos entre reglas considerando importancia, especificidad y orden de aparición.

Resultado técnico

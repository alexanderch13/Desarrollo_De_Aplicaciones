Formas combinadas y múltiples

Esta evidencia demuestra cómo CSS puede seleccionar elementos de acuerdo con relaciones jerárquicas y de vecindad, además de agrupar varios selectores en una sola regla cuando comparten la misma presentación.

Requisito de la práctica

La guía solicita por lo menos 7 casos combinados y 5 casos múltiples. La implementación incluye 10 combinaciones documentadas y 5 agrupaciones principales.

Demostración de selectores combinados

Los casos se apoyan en relaciones de descendencia, hijo directo, hermano adyacente y hermanos generales.

C1 // Hijo directo

nav > a alcanza solamente enlaces que son hijos inmediatos del elemento de navegación.

Al pasar el cursor, el borde inferior confirma visualmente la selección.

C2 // Hermano adyacente

header + nav selecciona el navegador porque aparece inmediatamente después del encabezado.

La sombra del navegador es la evidencia de esta relación.

C3 // Descendiente

section article aplica una transición a artículos ubicados dentro de una sección.

La relación puede tener uno o más niveles intermedios.

C4 // Hijo directo

article > h3 estiliza únicamente títulos que son hijos directos de un artículo.

El borde inferior del título permite comprobar la regla.

C5 // Adyacencia

h2 + p selecciona únicamente el primer párrafo inmediatamente posterior a cada h2.

Otros párrafos posteriores no cumplen la misma condición.

C6 // Hermanos generales

h3 ~ p selecciona todos los párrafos hermanos que aparecen después de un h3.

Por ello estos textos reciben el desplazamiento interno definido en CSS.

C8-C10 // Estructuras multinivel

section > aside, main > section > article > p y table tbody > tr muestran que los combinadores pueden encadenarse.

Esto permite describir relaciones estructurales muy precisas sin alterar el HTML.

Demostración de selectores múltiples

Los selectores separados por comas permiten compartir una declaración entre diferentes elementos y reducen repetición.

Grupos implementados

  1. h1, h2, h3 para características tipográficas comunes.
  2. header, footer para zonas estructurales superior e inferior.
  3. section, article, aside para control de desbordamiento de texto.
  4. ul, ol para márgenes consistentes en listas.
  5. table, caption, th, td para presentación numérica tabular.

Ventaja

Agrupar selectores evita repetir exactamente las mismas propiedades en reglas separadas, por lo que mejora la legibilidad y el mantenimiento de la hoja de estilos.

Registro y conclusión

Las pruebas mostraron que los combinadores permiten expresar relaciones entre elementos sin agregar contenedores genéricos al DOM. Los selectores múltiples reducen duplicación cuando varios elementos necesitan propiedades equivalentes.

Resultado de verificación

Se comprobó que las diez reglas combinadas y los cinco grupos múltiples producen efectos visibles sin emplear etiquetas <div> ni estilos en línea.

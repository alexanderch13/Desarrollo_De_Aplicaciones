# Experiencia de Práctica N.º 05 — Utilización de medidas

Esta carpeta desarrolla las dos partes solicitadas por la guía:

## A. Medidas absolutas

- `index.html`
- `medidasabsolutas.css`
- `base.css`

Se implementan 7 unidades absolutas listadas por la guía:

- cm
- mm
- Q
- in
- pc
- pt
- px

Para cada unidad se incluyen 3 demostraciones distintas, dando un total de 21 casos.

## B. Medidas relativas

- `medidasrelativas.html`
- `medidasrelativas.css`
- `base.css`

Se implementan las unidades relativas listadas en el marco teórico:

- em
- ex
- ch
- rem
- lh
- vw
- vh
- vmin
- vmax

Cada una tiene 3 demostraciones. Además se agregan 3 casos con `%` como comparación complementaria.

## Criterios de calidad aplicados

- No se utiliza ninguna etiqueta `<div>`.
- No se utilizan estilos inline.
- Se utilizan elementos semánticos: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `table` y `footer`.
- Las tablas incluyen `caption`, `colgroup`, `thead`, `tbody`, `rowspan` y `colspan`.
- El diseño conserva la identidad visual negro/rojo de las experiencias anteriores.
- Las páginas son responsivas y permiten comparar visualmente las unidades.

Configuración de colores HSL

Pruebas con tono, saturación y luminosidad usando la función válida hsl() de CSS.

./nombres ./rgb ./hex ./hsl ./opacidad

Objetivo de esta parte

La guía denomina esta parte «H LS» y solicita el archivo coloreshls.css; el marco teórico describe el modelo HSL. Por eso se conserva el nombre de archivo de la guía y se usa la función CSS válida hsl().

Control de cumplimiento

Esta página implementa 6 casos, superando el mínimo de tres solicitado. No utiliza etiquetas <div> ni estilos en línea.

Demostraciones visuales

Cada tarjeta utiliza el mismo patrón estructural para que la diferencia principal observada sea la forma en la que se define o modifica el color.

Conclusión

HSL separa el tono, la saturación y la luminosidad, por lo que resulta intuitivo para construir variaciones de una misma familia cromática. La comparación permite observar cómo la saturación y la luminosidad modifican la intensidad visual.

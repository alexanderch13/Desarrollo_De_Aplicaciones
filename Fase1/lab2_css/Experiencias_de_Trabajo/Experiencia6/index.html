Configuración de colores por nombre

Uso de nombres CSS para definir colores de fondo y borde en una interfaz técnica.

./nombres ./rgb ./hex ./hsl ./opacidad

Objetivo de esta parte

La guía pide crear colorespornombre.css y utilizar por lo menos 3 casos con colores expresados mediante su nombre.

Control de cumplimiento

Esta página implementa 6 casos, superando el mínimo de tres solicitado. No utiliza etiquetas <div> ni estilos en línea.

Demostraciones visuales

Cada tarjeta utiliza el mismo patrón estructural para que la diferencia principal observada sea la forma en la que se define o modifica el color.

Caso 1

Familia roja para estados críticos.

crimson / darkred

Caso 2

Familia naranja para advertencias.

orangered / orange

Caso 3

Familia azul para información.

midnightblue / deepskyblue

Caso 4

Contraste violeta para clasificación.

indigo / violet

Caso 5

Familia verde para estado correcto.

darkgreen / limegreen

Caso 6

Escala neutra para elementos secundarios.

dimgray / silver

Registro comparativo

Conclusión

Los nombres CSS permiten trabajar con colores de manera legible y directa. Son útiles cuando se busca claridad en el código, aunque ofrecen menos control numérico que RGB, hexadecimal o HSL.

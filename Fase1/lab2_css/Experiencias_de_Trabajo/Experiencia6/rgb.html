Configuración de colores con RGB

Comparación entre sintaxis RGB con valores enteros y porcentajes.

./nombres ./rgb ./hex ./hsl ./opacidad

Objetivo de esta parte

La guía exige por lo menos 3 casos y pide probar RGB tanto con valores enteros como con porcentajes.

Control de cumplimiento

Esta página implementa 6 casos, superando el mínimo de tres solicitado. No utiliza etiquetas <div> ni estilos en línea.

Demostraciones visuales

Cada tarjeta utiliza el mismo patrón estructural para que la diferencia principal observada sea la forma en la que se define o modifica el color.

Caso 1

RGB entero para rojo principal.

rgb(220, 38, 38)

Caso 2

RGB entero para fondo oscuro.

rgb(21, 21, 21)

Caso 3

RGB entero para información.

rgb(30, 64, 175)

Caso 4

RGB porcentual rojo.

rgb(86%, 15%, 15%)

Caso 5

RGB porcentual cian.

rgb(0%, 45%, 55%)

Caso 6

RGB porcentual violeta.

rgb(42%, 18%, 68%)

Registro comparativo

Conclusión

RGB permite controlar directamente la intensidad de rojo, verde y azul. La experiencia demuestra que los mismos canales pueden escribirse mediante enteros o porcentajes, manteniendo el mismo modelo de composición de color.
